## Descripción del proyecto

Sistema web para la gestión de inventarios de una ferretería, permitiendo el control de productos, proveedores, entradas y salidas de stock, así como la generación de reportes básicos.

## Objetivo general

Diseñar la documentación y los prototipos de un sistema de control de inventario para ferretería, aplicando los principios de Ingeniería de Software para modelar la solución.

## Funcionalidades principales

1. **Gestión de productos:** Registrar, editar, eliminar y consultar productos del inventario con código, nombre, categoría, precio y stock.
2. **Control de existencias:** Actualizar automáticamente el stock al registrar entradas (compras) y salidas (ventas).
3. **Gestión de proveedores:** Mantener un registro de proveedores con datos de contacto y productos que suministran.
4. **Reportes básicos:** Generar reportes de productos con bajo stock, valor total del inventario y movimientos por período.
